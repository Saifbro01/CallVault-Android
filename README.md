# CallVault — Android Call Recorder & Private Vault

Universal Call Recorder for Samsung Galaxy A13, OPPO, Xiaomi, Vivo, Pixel, and all Android devices (Android 8.0 - 15).

## 🚀 1-Click Cloud APK Build via GitHub Actions
1. Push or upload this repository to GitHub.
2. Open the **Actions** tab (works on mobile phone browsers too!).
3. Click **Build CallVault Android APK** -> **Run workflow**.
4. In 2 minutes, download ready-to-use APKs from Artifacts:
   - `CallVault-Universal-Android.apk` (Universal for all phones)
   - `CallVault-Samsung-Galaxy-A13.apk` (Samsung Galaxy A13)
   - `CallVault-OPPO-F19.apk` (OPPO F19)

No Android Studio or high-end PC required!
